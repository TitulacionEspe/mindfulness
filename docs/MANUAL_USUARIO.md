# Manual de usuario - Nidara

## 1. Proposito

Nidara es una aplicacion de apoyo para mindfulness e higiene del sueno dirigida a la comunidad universitaria. Permite registrar habitos, realizar actividades de relajacion, escribir notas personales y gestionar citas de acompanamiento.

> La aplicacion no realiza diagnosticos ni reemplaza la atencion de un profesional de salud. Si necesitas ayuda urgente, contacta a los servicios de emergencia o de bienestar correspondientes.

## 2. Ingreso a la aplicacion

1. Abre Nidara y selecciona **Crear cuenta** si es tu primera vez.
2. Ingresa tu nombre, correo activo y una contrasena segura.
3. Revisa y acepta el consentimiento informado para continuar.
4. En los siguientes accesos, escribe tu correo y contrasena en la pantalla de inicio de sesion.
5. Si olvidas la contrasena, utiliza la opcion de recuperacion y sigue el enlace enviado a tu correo.

Al ingresar por primera vez como paciente, configura tu hora habitual de dormir y despertar. Puedes modificarla despues desde **Habitos**.

## 3. Secciones para pacientes

| Seccion | Que puedes hacer |
| --- | --- |
| **Inicio** | Consultar accesos rapidos y abrir la guia de funciones disponibles. |
| **Actividades** | Realizar ejercicios de respiracion, relajacion, mindfulness y sesiones con sonidos. Selecciona una actividad y sigue las indicaciones en pantalla. |
| **Diario** | Registrar pensamientos o notas personales breves y consultar tus entradas previas. |
| **Citas** | Solicitar una cita, revisar solicitudes y consultar las citas registradas. |
| **Habitos** | Definir horarios de descanso, dias de mayor carga academica, recordatorios, tono de transicion y tema visual. Guarda los cambios al finalizar. |
| **Perfil** | Consultar tu progreso, ajustar accesibilidad, leer el consentimiento, pedir ayuda y cerrar sesion. |

El boton circular de la parte superior abre el asistente de Nidara. Este ofrece acompanamiento general; no sustituye una consulta profesional.

## 4. Accesibilidad y descanso visual

En **Perfil > Accesibilidad** puedes elegir el tamano del texto y activar el apoyo visual para personas con dificultad de diferenciacion rojo-verde. En **Habitos > Tema preferencial** puedes cambiar entre modo claro y modo oscuro.

Estas preferencias se guardan para los proximos accesos. El modo oscuro es apropiado para entornos con poca luz; el modo claro puede resultar mas comodo durante el dia.

## 5. Uso por profesionales y administradores

El contenido disponible depende del rol asignado a tu cuenta. El sistema redirige automaticamente a cada modulo:

| Rol | Funciones principales |
| --- | --- |
| **Profesional** | Consultar pacientes, asignar cuestionarios o actividades, gestionar actividades y revisar citas. |
| **Administrador** | Acceder al panel de administracion y a las funciones de gestion habilitadas para ese perfil. |

## 6. Recomendaciones

- Usa un correo al que tengas acceso para recuperar tu contrasena.
- No compartas tus credenciales con otras personas.
- Cierra sesion desde **Perfil** cuando utilices un dispositivo compartido.
- Si una funcion no carga, revisa tu conexion a Internet e intenta nuevamente.
